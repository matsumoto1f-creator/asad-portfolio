The ticket log.

Most dealer-site work is a queue of client requests: swap a banner, fix a price, build a specials page by Friday. Below are five requests I took from real problems on live dealer sites, and the fix I built for each in the Halcyon demo.

HC-101Banner

A Labor Day banner still running in October

Request
Seasonal slides and promo strips outlive their offers.
Shipped
The promo strip carries data-expires, and jQuery removes it the day after the offer ends. No ticket needed.
See the strip
HC-102Pricing

A price stack that doesn’t add up

Request
MSRP, discount, rebate and doc fee typed by hand, so the total drifts.
Shipped
Every line comes from one inventory record and the total is computed. Each line has an (i) disclaimer in one shared modal.
See a stack
HC-103Specials

“View Inventory (7)” when there are two

Request
Offer pages hard-code counts and headlines that go stale.
Shipped
The specials page counts matching stock from the same data the SRP uses, and computes “$4,700 off” from the unit’s own lines.
See specials
HC-104Mobile

A 1920×600 slide that crops the car on phones

Request
Text baked into the art, and the car cut off below 768px.
Shipped
Real HTML text over the slide, a <picture> source for phones, a reflowed caption, and a pause button for the carousel.
See the hero
HC-105Access

Images without alt text, a raw template key as a heading

Request
Accessibility left to an overlay widget.
Shipped
Alt text on every image, one H1 per page, real buttons, visible focus rings, keyboard-operable menus and gallery, reduced-motion support.
Tab through it
